# Plotting Scripts

This directory contains the scripts used to generate the figures presented in the manuscript:

**Land-Moisture Preconditioning and Oceanic Maintenance of the 2023 Extreme Rainfall over North China**

## Figure reproduction

| Figure | Method | Script | Input data |
| --- | --- | --- | --- |
| Fig. 1 | NCL | `Fig01.ncl` | Shapefiles archived in the associated Zenodo dataset |
| Fig. 2 | NCL | `Fig02.ncl` | Shapefiles archived in the associated Zenodo dataset |
| Fig. 3 | Origin | — | Excel source data archived on Zenodo |
| Fig. 4 | NCL | `Fig04.ncl` | Processed/model data described in the associated dataset |
| Fig. 5 | NCL | `Fig05.ncl` | Processed/model data described in the associated dataset |
| Fig. 6 | Origin | — | Excel source data archived on Zenodo |
| Fig. 7 | NCL | `Fig07.ncl` | Processed/model data described in the associated dataset |
| Fig. 8 | NCL | `Fig08.ncl` | NetCDF source data archived on Zenodo |
| Fig. 9 | NCL | `Fig09.ncl` | CSV source data archived on Zenodo |
| Fig. 10 | NCL | `Fig10.ncl` | CSV source data archived on Zenodo |
| Fig. 11 | NCL | `Fig11.ncl` | CSV source data archived on Zenodo |

Figures 3 and 6 were generated using Origin from the Excel source data provided in the associated Zenodo dataset.

The NCL scripts require the NCAR Command Language (NCL), including the standard contributed and WRF libraries.
